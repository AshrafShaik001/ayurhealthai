## 🌟 Overview

AyurHealthAI is a full-stack wellness application that brings the 5,000-year-old science of Ayurveda into the digital age through the power of artificial intelligence. Users discover their **Prakriti** (Ayurvedic constitution — Vata, Pitta, or Kapha), then receive hyper-personalised guidance across diet, daily routine, herbal remedies, seasonal health practices, and recipe recommendations — all generated by Claude AI and grounded in classical Ayurvedic texts.

Whether you are exploring Ayurveda for the first time or are a seasoned practitioner, AyurHealthAI provides:

- **Instant dosha assessment** through a clinically-inspired quiz
- **AI-generated seasonal wellness plans** (Ritucharya) tailored to your constitution
- **Real-time symptom analysis** with Ayurvedic root-cause explanations
- **Personalised Dinacharya** (daily routine) planner with progress tracking
- **Dosha-specific recipes** and food compatibility checking

### Authentication Flow

```
User submits login form
        │
        ▼
POST /api/auth/login
  → bcrypt.compare(password, hash)
  → jwt.sign({ userId, email, name }, JWT_SECRET, { expiresIn: '7d' })
  → Return { token, user }
        │
        ▼
AuthContext.authLogin(token, user, rememberMe)
  → Store in localStorage (remember me) or sessionStorage
  → Axios interceptor: Authorization: Bearer {token} on every request
        │
        ▼
PrivateRoute checks isAuthenticated
  → token + user both present → render children
  → otherwise → redirect /login?redirect=...
```

## 🚀 Quick Start

> **Prerequisites:** Node.js ≥ 18, npm ≥ 9, a MongoDB Atlas account, an Anthropic API key

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ayurhealthai.git
cd ayurhealthai
```

### 2. Install all dependencies

```bash
npm run install:all
```

This installs dependencies for the root, client, and server in one command.

### 3. Configure environment variables

```bash
cp server/.env.example server/.env
```

Open `server/.env` and fill in your values:

```env
PORT=5001
NODE_ENV=development
MONGO_URI=mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/ayurai?retryWrites=true&w=majority
CLIENT_ORIGIN=http://localhost:5173
ANTHROPIC_API_KEY=sk-ant-...
JWT_SECRET=your_super_secret_jwt_key_minimum_32_chars
```

> See [Environment Variables](#-environment-variables) for detailed descriptions.

### 4. Run in development mode

```bash
npm run dev
```

This starts both the Express API server (`:5001`) and the Vite dev server (`:5173`) concurrently.

| Service | URL |
|---|---|
| Frontend | http://localhost:5173 |
| Backend API | http://localhost:5001/api |
| Health Check | http://localhost:5001/health |

## 🔐 Environment Variables

All environment variables belong in `server/.env` (never committed to git).

| Variable | Required | Default | Description |
|---|---|---|---|
| `PORT` | No | `5001` | Express server port |
| `NODE_ENV` | No | `development` | Environment (`development` / `production`) |
| `MONGO_URI` | **Yes** | — | MongoDB Atlas connection string |
| `CLIENT_ORIGIN` | **Yes** | `http://localhost:5173` | Frontend URL (for CORS) |
| `ANTHROPIC_API_KEY` | **Yes** | — | Anthropic Claude API key |
| `JWT_SECRET` | **Yes** | — | Secret for signing JWTs (≥ 32 chars) |

### Getting Your API Keys

| Service | Where to get it |
|---|---|
| **MongoDB URI** | [MongoDB Atlas](https://cloud.mongodb.com) → Cluster → Connect → Drivers |
| **Anthropic API Key** | [console.anthropic.com](https://console.anthropic.com) → API Keys |
| **JWT Secret** | Generate locally: `node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"` |
